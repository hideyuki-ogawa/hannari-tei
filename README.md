# 京料理・仕出し「はんなり亭」古いサイト改善教材

祇園四条・宮川町界隈の架空の老舗京料理店を題材にした、2000年代初頭風の静的サイトです。
阿部寛公式サイトのような素朴なHTMLの雰囲気を参考にしていますが、同サイトのコード・画像・文章は使っていません。
全6ページ。ビルド、インストール、外部サービス、JavaScriptは不要です。

## まず見る

`index.html` をブラウザーで開いてください。画像も同梱しているので、インターネット接続なしで表示できます。
画面幅約1,000px以上を想定。スマートフォンの横スクロールは、改善前の教材として意図的に残しています。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリ（例：`hannaritei-retro`）を作ります。
2. このフォルダーの**中身**をリポジトリの最上位にアップロードし、コミットします。`index.html` が最上位にある状態にしてください。ZIP自体をアップロードしてもサイトにはなりません。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** を **Deploy from a branch** にします。
5. **Branch** に `main`、フォルダーに **/(root)** を選び、**Save** を押します。
6. 公開処理が終わったら、Pages画面に表示されるURLを開きます。通常は `https://ユーザー名.github.io/リポジトリ名/` です。

プランや組織の設定で公開機能が制限されている場合は、利用できるリポジトリと権限を確認してください。
`.nojekyll` は同梱済みです（ブラウザーのアップロード画面で隠しファイルが選べなければ、省略してもこの構成は表示できます）。
404になる場合は、公開対象のブランチ・フォルダーと `index.html` の位置を確認してください。画像だけ表示されない場合は `assets` フォルダーとファイル名の大文字・小文字を確認してください。

公開手順の根拠：[GitHub公式ドキュメント：公開元の設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)（2026-10-27確認）。
この納品時点でGitHubへのアップロード・公開は行っていません。

## 意図した「古さ」

- tableでの段組、970pxの固定幅、左寄せの画面。
- 小さな明朝体、青い下線リンク、訪問済みの紫リンク。
- 密なナビ、重複する連絡先、細かい但し書き、小さな写真。
- 2004年で止まった更新日、古い年末告知、NEW表記。
- 電話・FAX中心の予約、現金支払い、曖昧な配達条件。
- 固定表示のアクセスカウンター、古いブラウザーの推奨文。

文字コードは編集しやすいUTF-8です。当時風の見た目と、現代のブラウザーで開けることを両立しています。
古いブラウザーでの動作確認は行っていません。「IE6で確認済み」は演出用の架空の設定です。

## 教材としての利用

地域名・駅名は実在しますが、店名・沿革・人物・価格・店舗の所在地・連絡先は架空の設定です。常連と紹介で経営が安定し、改善予算はあるもののサイトが後回しになっていた、という教材上の背景を設定しています。電話番号は `XXX` を含む無効な表記にしてあります。
料理・外観写真はAI生成で、実店舗や実際の提供料理の写真ではありません。店舗の番地は設定せず、略図は実際の店舗位置や経路を示しません。
サイトは実際の予約・入力・送信・決済・アクセス集計を行いません。外部フォント・解析・外部画像の読み込みもありません。
研修用の改変・配布・GitHub Pages掲載を想定して作成しています。改善版も架空の店舗であることを明記し、実在する番号や個人情報へ置き換えないでください。
